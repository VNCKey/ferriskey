# 🗺️ Roadmap: 01 - Rust Foundations

## 🎯 Objetivos de Aprendizaje
1. Conocer la herramienta `Cargo`, el compilador `rustc` y la estructura de un proyecto Rust.
2. Dominar los archivos `Cargo.toml`, `Cargo.lock` y los directorios `src/` y `target/`.
3. Entender los perfiles `dev` vs `release` y la inspección de binarios nativos.
